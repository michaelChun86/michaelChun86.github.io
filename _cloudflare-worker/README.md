# 방문자 통계 설정 안내

관리자 대시보드는 `https://michaelchun86.github.io/mc-admin-2027/` 입니다.
**초기 비밀번호는 `chun2027`** — 4단계에서 꼭 바꾸세요.

전체 흐름은 두 덩어리입니다.

```
1) GA4 로 방문자를 수집한다        ← 이것만 해도 GA4 앱/웹에서 통계를 볼 수 있음
2) 그 숫자를 내 대시보드로 끌어온다 ← 선택. 안 하면 대시보드는 샘플 숫자를 보여줌
```

급하지 않다면 **1단계만 해도 충분합니다.** 2단계는 나중에 해도 됩니다.

# 1부 — GA4 연결 (필수, 5분)

## 1단계 — 측정 ID 만들기

1. [analytics.google.com](https://analytics.google.com) 접속
2. 좌측 하단 **관리(톱니)** → **만들기** → **속성**
3. 속성 이름 `Michael Chun` → 만들기
4. 플랫폼 **웹** 선택 → URL 에 `https://michaelchun86.github.io` 입력
5. 만들어진 **측정 ID** (`G-XXXXXXXXXX`) 복사

> ⚠️ 달라게임즈와 **별개의 속성**으로 만드세요.
> 같은 ID 를 쓰면 두 사이트 방문자가 한 통계에 섞입니다.

## 2단계 — 사이트에 넣기

`analytics.js` 맨 위의 이 줄을 채웁니다.

```js
var MEASUREMENT_ID = "";     ←  "G-XXXXXXXXXX" 를 넣으세요
```

같은 값을 `mc-admin-2027/admin.js` 의 아래 줄에도 적어두면
대시보드 하단에 어떤 속성을 보고 있는지 표시됩니다. (표시용, 동작과 무관)

```js
var MEASUREMENT_ID = "";
```

측정 ID 를 알려주시면 제가 넣어서 배포해 드리겠습니다.

## 3단계 — 확인

배포 후 사이트를 열고, GA4 의 **보고서 → 실시간** 에 내가 잡히면 성공입니다.
누적 보고서에 숫자가 나타나기까지는 최대 24~48시간 걸립니다. (정상입니다)

## 4단계 — 관리자 비밀번호 바꾸기

1. `https://michaelchun86.github.io/mc-admin-2027/` 접속 (https 여야 합니다)
2. F12 → 콘솔에 입력: `await AdminPIN.hash("새비밀번호")`
3. 출력된 긴 문자열을 `mc-admin-2027/admin.js` 의 `PIN_SHA256` 에 붙여넣기

> 이 잠금은 **우연히 들어온 사람을 막는 자물쇠**이지 보안이 아닙니다.
> 정적 사이트라 검사가 브라우저 안에서 일어나므로 마음먹으면 우회됩니다.
> 실제 방어선은 "주소를 모르면 못 들어온다" 입니다. 그래서 이 경로는
> `robots.txt` 에도 적지 않았습니다 — 적는 순간 "여기 관리자 페이지가
> 있다"고 공개하는 셈이라 역효과입니다.
> 노출되는 것은 집계된 숫자뿐이고 개인정보는 없습니다.

# 2부 — 대시보드에 실데이터 넣기 (선택, 15분)

## 왜 중계 서버가 필요한가

브라우저는 GA4 를 직접 못 읽습니다. 구글이 **서비스 계정 키**를 요구하는데,
그 키를 웹페이지에 넣으면 소스를 여는 누구나 볼 수 있기 때문입니다.

```
관리자 페이지  ──(그냥 요청)──▶  Worker  ──(키로 인증)──▶  GA4
              ◀──(숫자 JSON)──          ◀──(원본 데이터)──
```

키는 Cloudflare 에 보관되어 브라우저로 나가지 않습니다. 전부 무료입니다.

> 달라게임즈용 Worker 를 이미 만들어 두셨다면, **서비스 계정 키는 같은 것을
> 재사용**할 수 있습니다(아래 2-3~2-4 생략). 다만 Worker 자체는 속성 ID 가
> 하나씩만 들어가므로 **새로 하나 더 배포**해야 합니다.

## 1단계 — GA4 속성 ID 찾기

**측정 ID(`G-...`)와 다른 값입니다.** 숫자 9~10자리입니다.

관리(톱니) → **속성 설정** → **속성 세부정보** → 우측 상단 **속성 ID** 복사

## 2단계 — 구글 클라우드에서 키 만들기 (기존 키 재사용 시 생략)

### 2-1. 프로젝트
[console.cloud.google.com](https://console.cloud.google.com) → **새 프로젝트** → 이름 `chun-analytics`

### 2-2. API 켜기
**API 및 서비스** → **라이브러리** → `Google Analytics Data API` 검색 → **사용**

### 2-3. 서비스 계정
**사용자 인증 정보** → **만들기** → **서비스 계정** → 이름 `ga4-reader` → 역할 비워두고 **완료**

### 2-4. 키 내려받기
서비스 계정 클릭 → **키** 탭 → **키 추가** → **새 키 만들기** → **JSON**

> **이 파일이 곧 열쇠입니다. 절대 공유·업로드 금지.**
> 이 저장소에도 넣지 마세요.

## 3단계 — GA4 에 읽기 권한 주기

이걸 빼먹으면 나중에 **403 오류**가 납니다.

GA4 → **관리** → **속성 액세스 관리** → 우측 상단 **+** → **사용자 추가**
→ JSON 의 `client_email` 값 붙여넣기 → 역할 **뷰어** → 추가

> 기존 키를 재사용하는 경우에도 **새 속성에 다시 초대**해야 합니다.

## 4단계 — Cloudflare Worker 배포

1. [dash.cloudflare.com](https://dash.cloudflare.com) 로그인 (무료)
2. **Workers & Pages** → **Create** → **Start with Hello World!** → **Deploy**
3. 이름은 `mc-ga4` 처럼 달라게임즈용과 구분되게 지으세요
4. **Edit code** → 편집기 내용을 전부 지우고 이 폴더의 **`worker.js`** 를 통째로 붙여넣기
5. 우측 상단 **Deploy**

주소가 생깁니다. 예: `https://mc-ga4.your-name.workers.dev`

### 4-1. 변수와 시크릿 넣기

Worker 화면 → **Settings** → **Variables and Secrets**

| 이름 | 종류 | 값 |
|---|---|---|
| `GA4_PROPERTY_ID` | Text | 2부 1단계의 숫자 9~10자리 |
| `ALLOWED_ORIGIN` | Text | `https://michaelchun86.github.io` |
| `GA_SERVICE_ACCOUNT_JSON` | **Secret** | 내려받은 JSON 내용 **전체** (`{` 부터 `}` 까지) |

넣은 뒤 **Deploy** 를 한 번 더 눌러야 반영됩니다.

### 4-2. 확인

브라우저에서 Worker 주소를 그냥 열어보세요. 이런 JSON 이 보이면 성공입니다.

```json
{"todayUsers":12,"todayDeltaPct":20,"weekUsers":84,...}
```

`{"error":"..."}` 가 보이면 아래 [문제 해결] 참고.

## 5단계 — 대시보드에 연결

`mc-admin-2027/admin.js` 의 이 한 줄만 채우면 끝입니다.

```js
var API_ENDPOINT = "https://mc-ga4.your-name.workers.dev";
```

연결되면 화면 위의 **"샘플 데이터입니다"** 빨간 배너가 자동으로 사라집니다.
주소를 알려주시면 제가 넣어서 배포해 드리겠습니다.

## 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `403 ... permission` | 2부 3단계를 안 했거나 이메일 오타. 속성 액세스 관리에서 뷰어로 등록됐는지 확인 |
| `토큰 발급 실패: invalid_grant` | 키가 잘렸습니다. JSON 을 통째로 다시 넣으세요 |
| `속성 ID 미설정` | 변수 저장 후 **Deploy** 를 안 눌렀습니다 |
| `속성 ID 는 숫자여야 합니다` | 측정 ID(`G-...`)를 넣으셨습니다. 2부 1단계의 숫자를 넣으세요 |
| 숫자가 전부 0 | 정상입니다. GA4 는 누적 데이터 반영에 최대 24~48시간 걸립니다 |
| 대시보드에 여전히 샘플 | 2부 5단계 주소를 안 넣었거나 오타. Worker 주소를 직접 열어 JSON 이 나오는지 먼저 확인 |
| 내 방문이 통계에 안 잡힘 | 정상입니다. `analytics.js` 는 localhost 에서 전송하지 않습니다 |

## 비용과 한도

전부 **무료 범위 안**입니다.

- Cloudflare Workers 무료: 하루 10만 요청 (이 대시보드는 하루 몇십 건 수준)
- GA4 Data API 무료: 하루 25,000 토큰 (한 번 열 때 10건 조회)

Worker 가 결과를 **5분간 캐시**하므로 새로고침을 연타해도 GA4 를 계속 부르지 않습니다.
